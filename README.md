# TTS Automation Bot

Bot untuk generate voice TTS dan menjalankan automation berbasis Node.js.

## Features
- Generate voice dari text
- Auto-run bot via VBS / BAT
- Panel control

## Tech Stack
- Node.js
- PM2 (optional)
- TTS API

## Installation
```bash
git clone https://github.com/username/tts-bot.git
cd tts-bot
npm install
